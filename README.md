# 🏠 Residential Construction Cost Estimator

An end-to-end Data Science project that predicts preliminary residential construction costs using Machine Learning and deploys the model as an interactive Streamlit web application.

---

## 📌 Project Overview

This project demonstrates how Machine Learning can support early-stage construction cost estimation.

Users can input basic property information, and the application provides an estimated construction cost to support preliminary budgeting and feasibility assessment.

## ⚠️ Disclaimer

This application is a proof-of-concept developed for educational and demonstration purposes.

The prediction model was trained using a **synthetic dataset** generated from realistic residential construction scenarios and Quantity Survey (QS) domain knowledge.

Predicted values should be used only as preliminary cost estimates and should not replace a detailed Bill of Quantities (BOQ) or professional Quantity Survey (QS) analysis.
